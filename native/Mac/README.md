# Ridgeline для macOS · Unreal Engine 5

Нативный проект для Apple Silicon. Unreal рисует рельеф, небо, крыло, стропы и руки пилота. При каждом новом спуске строится ущелье длиной 3,2 км с 12 воротами, скальными полками, хвойными деревьями и фотограмметрическими валунами. Освещение, тени, размытие движения и хроматическую аберрацию рассчитывает рендерер UE.

Динамика крыла общая с браузерной игрой. Apple JavaScriptCore исполняет [модель полёта](../../src/flight.js) с шагом 1/240 секунды. Нативный код передаёт координаты рельефа и препятствий и забирает положение подвески, крен и состояние органов управления. Прогноз глайда учитывает те же коллизии и органы управления. Для него используется отдельное состояние модели.

## Сборка приложения

Нужны полный клон репозитория, Xcode с компилятором Metal и Unreal Engine для Mac. Проект ориентирован на UE 5.6. Скрипт подготовки импортирует GLB и текстуры, создаёт материалы и игровой уровень, затем запускает упаковку в конфигурации Development.

```sh
cd native/Mac
./test-flight.sh
UE_ROOT="/Users/Shared/Epic Games/UE_5.6" ./build-mac.sh
```

Сборка сохраняется в `Builds/`. В конце скрипт выводит путь к приложению. Сгенерированные ассеты находятся в `Content/Ridgeline/`. После подготовки проекта уровень `AlpinePass` можно открыть в редакторе. Для проверки физики через `test-flight.sh` достаточно macOS и инструментов командной строки Xcode.

## Управление

| Клавиша | Действие |
| --- | --- |
| Enter / R | Старт или пауза / сброс полёта |
| A / S | Левая клеванта, быстро / плавно |
| F / G | Правая клеванта, плавно / быстро |
| Пробел / Q / E | Обе клеванты / вес влево / вправо |
| ↑ / ↓ | Открыть / закрыть триммеры |
| C / H / M | Камера / прогноз глайда / шум потока |
| V / N | Переключить проксимити и свободный полёт / сгенерировать линию |

Зелёный пунктир показывает расчётный свободный путь, жёлтый предупреждает о промахе мимо ворот, красный отмечает подход к препятствию или поверхности.

Купол из 27 ячеек, пилот, руки, три вида хвойных и модели камней адаптированы из ассетов Ridgeline. Источники фотографий поверхности и фотограмметрии указаны в [описании материалов](../../README.md#графика-и-материалы).
